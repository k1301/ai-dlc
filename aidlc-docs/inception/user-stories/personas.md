# User Personas

## Persona 1: 매장 고객 (Restaurant Customer)

### Basic Information
- **Name**: 김민준 (Kim Min-jun)
- **Age**: 28세
- **Role**: 매장 방문 고객
- **Tech Proficiency**: 중급 (스마트폰, 태블릿 사용에 익숙)

### Goals and Motivations
- **Primary Goal**: 빠르고 편리하게 음식을 주문하고 식사를 즐기고 싶다
- **Motivations**:
  - 직원을 불러서 기다리는 시간을 줄이고 싶다
  - 메뉴를 천천히 살펴보고 스스로 결정하고 싶다
  - 주문 내역을 확인하고 추가 주문을 쉽게 하고 싶다
  - 대기 시간 없이 즉시 주문하고 싶다

### Pain Points and Frustrations
- 바쁜 시간대에 직원을 불러도 오지 않아 답답하다
- 메뉴판을 보면서 직원에게 질문하기 어렵다
- 이전에 무엇을 주문했는지 기억하기 어렵다
- 추가 주문 시 다시 직원을 불러야 하는 번거로움

### Expectations
- 터치 몇 번으로 쉽게 주문할 수 있는 직관적인 인터페이스
- 메뉴 이미지와 설명을 보고 선택할 수 있는 기능
- 주문 전 장바구니에서 수량을 조절하고 확인할 수 있는 기능
- 주문 후 내가 무엇을 주문했는지 확인할 수 있는 기능
- 별도의 로그인 없이 바로 사용 가능한 시스템

### Technology Comfort Level
- 스마트폰 앱과 웹사이트 사용에 익숙함
- 터치 인터페이스에 능숙함
- 복잡한 설정이나 계정 생성은 피하고 싶음
- 직관적인 UI를 선호함

### User Journey Context
1. 매장에 도착하여 테이블에 착석
2. 테이블 위의 태블릿을 확인
3. 자동으로 메뉴 화면이 표시됨 (로그인 불필요)
4. 메뉴를 탐색하고 카테고리별로 확인
5. 원하는 메뉴를 장바구니에 추가
6. 장바구니에서 수량 조절 및 확인
7. 주문 확정
8. 주문 내역 확인
9. 필요시 추가 주문

## Persona 2: 매장 관리자 (Restaurant Manager)

### Basic Information
- **Name**: 박수진 (Park Su-jin)
- **Age**: 35세
- **Role**: 매장 운영 관리자 / 매장 주인
- **Tech Proficiency**: 중급 (PC, 태블릿 사용 가능, 관리 시스템 경험 있음)

### Goals and Motivations
- **Primary Goal**: 들어오는 주문을 실시간으로 확인하고 효율적으로 관리하여 매장 운영을 최적화하고 싶다
- **Motivations**:
  - 인건비를 절감하고 직원을 최소화하고 싶다
  - 주문 누락이나 실수를 방지하고 싶다
  - 테이블별 주문 상황을 한눈에 파악하고 싶다
  - 실시간으로 주문을 확인하여 빠르게 대응하고 싶다
  - 메뉴를 쉽게 수정하고 관리하고 싶다

### Pain Points and Frustrations
- 여러 테이블의 주문을 동시에 관리하기 어렵다
- 주문이 들어왔는지 늦게 확인하면 고객 불만이 발생한다
- 종이 주문서는 분실되거나 잘못 읽을 위험이 있다
- 메뉴를 변경할 때마다 메뉴판을 다시 인쇄해야 한다
- 테이블 회전율을 높이기 위해 테이블 상태를 빠르게 파악해야 한다

### Expectations
- 모든 테이블의 주문을 한 화면에서 볼 수 있는 대시보드
- 새 주문이 들어오면 즉시 알 수 있는 실시간 업데이트
- 테이블별 총 주문 금액을 한눈에 확인
- 주문 상태를 변경하고 관리할 수 있는 기능
- 잘못된 주문을 삭제할 수 있는 기능
- 테이블 이용 완료 처리를 간단하게 할 수 있는 기능
- 메뉴를 쉽게 추가/수정/삭제할 수 있는 관리 기능

### Technology Comfort Level
- PC와 태블릿을 업무에 사용하는 데 익숙함
- 관리 시스템과 대시보드 사용 경험이 있음
- 복잡하지 않은 인터페이스를 선호함
- 학습 시간 없이 바로 사용할 수 있는 시스템을 원함

### Responsibilities
- 매장 전체 운영 감독
- 주문 모니터링 및 주방 전달
- 테이블 상태 관리 (이용 중, 이용 완료)
- 메뉴 관리 (추가, 수정, 삭제)
- 과거 주문 내역 조회 및 확인
- 테이블 태블릿 초기 설정

### User Journey Context
1. 관리자 로그인 (16시간 세션)
2. 실시간 주문 모니터링 대시보드 확인
3. 새 주문이 들어오면 즉시 화면에 표시됨
4. 테이블별 주문 카드를 클릭하여 상세 내역 확인
5. 주문 상태를 변경 (대기중 → 준비중 → 완료)
6. 필요시 주문 삭제
7. 고객이 식사를 마치면 테이블 이용 완료 처리
8. 필요시 과거 주문 내역 조회
9. 메뉴 관리 (추가, 수정, 삭제)

## Persona Validation

### Coverage Check
- ✅ 모든 주요 사용자 유형이 페르소나로 표현됨 (고객, 관리자)
- ✅ 각 페르소나는 명확히 구분되며 중복이 없음
- ✅ 모든 기능 요구사항이 페르소나와 연결됨

### Distinctiveness Check
- ✅ **고객 페르소나**: 음식 주문 및 식사 경험에 집중
- ✅ **관리자 페르소나**: 매장 운영 및 주문 관리에 집중
- ✅ 두 페르소나는 완전히 다른 목표와 동기를 가짐

### Completeness Check
- ✅ 각 페르소나는 요구사항 문서의 사용자 유형과 일치
- ✅ 페르소나의 목표와 불만은 시스템 기능과 연결됨
- ✅ 페르소나의 기술 수준은 UI/UX 요구사항과 일치
